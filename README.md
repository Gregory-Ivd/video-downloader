# VideoDownloader (Smart Attic)

Завантажувач відео з YouTube і Facebook: customtkinter-інтерфейс поверх yt-dlp.

Відновлено 20.09.2026. Вихідних кодів старої збірки на машині не було —
структуру й тексти інтерфейсу витягнуто з `VideoDownloader – копія.exe`
(PyInstaller-архів, Python 3.14).

## Чому стара збірка перестала качати

У старий `.exe` була вшита бібліотека `yt_dlp` версії **2026.03.17**.
YouTube ламає видобувач раз на кілька тижнів; станом на 20.09.2026 він віддає
`HTTP Error 403: Forbidden` на медіа-URL усім збіркам, старішим за середину
вересня. Перевірено того ж дня на цій машині:

| yt-dlp | результат |
|---|---|
| 2026.03.17 (вшитий у стару збірку) | не перевірявся напряму, старший за обидва нижчі |
| 2026.07.04 (був у системі) | `HTTP Error 403` |
| 2026.08.19 (stable) | `HTTP Error 403` |
| 2026.09.16 (nightly) | качає і зводить нормально |

Аналіз посилання при цьому працював — список якостей приходив. Тому помилка
й вилазила саме після натискання Download.

## Що змінено в архітектурі

`yt_dlp` більше не вшивається в `.exe`. Застосунок викликає зовнішній
`yt-dlp.exe` і вміє його оновлювати кнопкою «Оновити yt-dlp».
Коли YouTube зламає видобувач наступного разу — перезбирати нічого не треба.

Пошук рушія, по порядку:

1. `yt-dlp.exe` поруч із застосунком (портативний варіант);
2. `%LOCALAPPDATA%\SmartAtticDownloader\yt-dlp.exe` (приватна копія);
3. `yt-dlp` у `PATH` (системна).

Якщо не знайдено жодної — тягне свіжий **nightly** з GitHub у приватну папку.
Саме nightly, бо stable зараз не працює з YouTube.

`ffmpeg` вшитий у `.exe` (звідси 118 МБ) — він не протухає, на відміну від
видобувача. Якщо є системний, береться бандлений.

## Збірка

```powershell
python -m pip install customtkinter pyinstaller
winget install -e --id Gyan.FFmpeg   # якщо ffmpeg ще немає; потім новий термінал
$ff = (Get-Command ffmpeg).Source
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name VideoDownloader --collect-all customtkinter `
  --add-binary "$ff;ffmpeg" main.py
```

Готовий файл — `dist\VideoDownloader.exe`.

## Відоме й неперевірене

- **Facebook не перевірявся.** yt-dlp тягне публічні відео FB без входу;
  закриті й ті, що вимагають логіну, — ні. Потрібне справжнє посилання,
  на якому ламалося.
- Ctrl+V прив'язаний до keycode фізичної клавіші V, бо на українській
  розкладці стандартна прив'язка до символу `v` не спрацьовує. Запасний
  варіант — права кнопка миші → «Вставити».
